# deine Misere! – CMS

Das CMS liegt unter `/admin/`.

Es kann per GitHub-Token im Browser:
- Titelbild ersetzen
- Logo ersetzen
- Texte bearbeiten
- Musik-Veröffentlichungen mit Cover hinzufügen/löschen
- Fotos hinzufügen/löschen
- Downloads hinzufügen/löschen

Der Bandname ist fest auf `deine Misere!` gesetzt.

Für GitHub Pages ist das Repository als statische Website geeignet. Das CMS selbst benötigt GitHub-API-Schreibzugriff und wird deshalb am besten lokal bzw. über eine separate, geschützte CMS-URL verwendet.


Neu: Das CMS kann jetzt auch Konzerte (hinzufügen, bearbeiten, löschen) und das Impressum bearbeiten. Das Impressum wird auf impressum.html aus content.json geladen. Rechtliche Vollständigkeit bitte selbst prüfen.
