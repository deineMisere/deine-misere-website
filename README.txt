deine Misere! Website

- Logo ist als vollständig weiße, intransparente PNG eingebunden und oben rechts im Hero-Bereich positioniert.
- Bandname wird überall als „deine Misere!“ geführt.
- CMS unter /admin/; Inhalte werden über content.json gepflegt.
- Veröffentlichung ist für GitHub + Vercel vorbereitet.
- Impressum vor Livegang prüfen/ergänzen.


Korrektur: Das Logo ist als opaque PNG erstellt und zusätzlich direkt als Data-URI in index.html eingebettet. Das Bandfoto wird auf Smartphones vollständig und ohne Zuschneiden dargestellt.
